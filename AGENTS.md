# MTAH 2027 possession lab

User instructions carried forward from the 27 October 2026 continuation note.

- Communicate in Turkish. Read `docs/RAPOR.md` before proposing an experiment;
  it is the single research log. Keep unsuccessful attempts and their reasons.
- Never expose competition data to any hosted LLM, including this assistant.
  Do not open, inspect, display, or print `data/`, `cache/`, `submissions/`,
  video frames, audio, transcripts, or frame-level predictions. Local scripts
  may process them and return aggregate scores, counts, ratios, and hashes only.
  In particular, never read `cache/asr/` into the conversation.
- Keep all match data and derivatives untracked. Do not publish research logs
  or derived reports/plots. The public export is an explicit allowlist in
  `tools/public/files.txt`, generated by `tools/export_public.py`.
- The public five-minute BAR-ATH window is a pipeline check only. Never choose
  a model, feature, parameter, or version using its score. No manual BAR-ATH
  labels/corrections or human-produced data about this game, for any purpose.
  Other games' open datasets are allowed. The official rules are under
  `external/more-than-a-hack-2027/`; verify their current upstream revision.
- Run GPU work only in Google Colab. Never interrupt another person's process
  or Colab session. Stop only sessions you created, when your work is finished.
  The user handles OAuth and tokens.
- The user's local connection is metered. Ask before downloading datasets,
  weights, or packages, and state the size. Use existing local Git objects and
  offline package caches when available. Large downloads belong on the Colab VM.
- Local branches and commits are authorized. Ask before any Git push. Preserve
  the collaborator's commits and all uncommitted work when integrating changes.
- Evaluate candidates with at least three training seeds and paired bootstrap
  over independent matches. Average Metrica noise draws within a game first.
  Use worst-case regret across external contexts; differences below 0.005 keep
  the current/simpler model. Never evaluate shared BiGRU on DFL as held out:
  its checkpoints trained on all seven DFL matches.
- Add each experiment at the end of the main table in `docs/RAPOR.md` section 3;
  put longer notes under a new round in section 4. Update section 1 when the
  default or established scores change. Do not promote an incomplete result.
- Python command convention on Windows: `.venv/Scripts/python.exe -I src/<script>.py`.
  Scripts must add their own `src/` import path when using isolated mode.
